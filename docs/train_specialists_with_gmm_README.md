# Train Specialists with GMM Enhancement Pipeline

## Overview

This pipeline trains all 11 specialist models independently and processes their outputs through GMM enhanced features for downstream use. It provides a unified way to train specialists without using the meta_labeling_hpo_sample_weighted pipeline.

## Specialists Trained

1. **Momentum Persistence**: Captures structural inertia and trend sustainability
2. **SMC Regime**: Smart Money Concepts focused on order blocks and liquidity sweeps  
3. **Volatility Burst**: Detects compression regimes and imminent expansion
4. **Volume Force**: Binary breakout classifier focused on order-flow impulse
5. **Macro Regime**: High-horizon trend and regime shift detection
6. **Meso Regime**: Intermediate-horizon cyclical and trend patterns
7. **Liquidity Regime**: Monitors market depth and capacity states
8. **Path Regime**: Analyzes the "roughness" and risk of the price path
9. **Risk Regime**: Focuses on tail-risk (VaR/CVaR) and volatility escalation
10. **Microstructure**: Analyzes spread volatility, price efficiency, and imbalance
11. **Spectral Energy**: Captures frequency-domain energy and dominant cycles

## Pipeline Architecture

### Step 1: Market Data Loading
- Loads market data using the standard Ares data loading infrastructure
- Validates data quality and coverage

### Step 2: Specialist Training
- Trains each specialist independently using their enhanced implementations
- Collects predictions and features from each specialist
- Handles training failures gracefully

### Step 3: Output Combination
- Combines all specialist outputs into a single DataFrame
- Prefixes column names with specialist names for traceability
- Aligns data on timestamps

### Step 4: GMM Enhancement
- Processes combined specialist outputs through GMM enhanced features
- Applies fractional differencing, advanced kinematics, and regime analysis
- Generates enhanced features with dual pipeline architecture

### Step 5: Result Storage
- Saves enhanced features to CSV files
- Stores individual specialist outputs separately
- Saves metadata and training summary
- Persists to versioned artifacts for downstream use

## Troubleshooting

### Common Issues

1. **Specialist Import Failures**
   - Check that all enhanced specialist modules are available
   - Verify dependencies are installed (lightgbm, xgboost, etc.)

2. **GMM Enhancement Failures**
   - GMM enhancement is optional - pipeline falls back to raw features
   - Check sklearn and scipy dependencies

3. **Memory Issues**
   - Training 11 specialists can be memory intensive
   - Use `--lookback-days` to limit data size if needed

4. **Data Loading Issues**
   - Verify market data is available for the specified symbol/timeframe
   - Check exchange connectivity and data permissions

### Performance Tips

1. **Parallel Training**: Specialists are trained sequentially but can be parallelized in future versions
2. **Data Limiting**: Use `--lookback-days` for faster testing on smaller datasets
3. **Selective Training**: Use `--specialists` to train only specific specialists when debugging
