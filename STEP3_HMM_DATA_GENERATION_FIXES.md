# Step 3 HMM Data Generation Fixes

## Issues Identified

### 1. Missing Composite Cluster Generation
**Problem**: Step 3 was processing HMM models and generating block states but was skipping the composite clustering step with the comment "Skip complex clustering to avoid crashes".

**Root Cause**: The step had the infrastructure for composite clustering but was intentionally bypassing it to avoid crashes.

**Impact**: No `composite_cluster_id` columns were being generated, which are paramount for the regime splitting system.

### 2. Incorrect Import in Composite Manager
**Problem**: The HMM composite manager was trying to import from `step1_7_hmm_regime_discovery` which doesn't exist.

**Root Cause**: The composite manager was looking for a non-existent module.

**Impact**: The composite manager couldn't create HMM composite clusters when needed.

## Fixes Implemented

### 1. Fixed Composite Manager Import
**File**: `src/utils/hmm_composite_manager.py`

**Change**: Updated import to use the correct module name.
```python
# Before (incorrect)
from src.training.steps.step1_7_hmm_regime_discovery import (
    run_step_enhanced as run_step,
)

# After (correct)
from src.training.steps.step3_hmm_regime_discovery import (
    run_step_enhanced as run_step,
)
```

### 2. Added Composite Cluster Generation Logic
**File**: `src/training/steps/step3_hmm_regime_discovery.py`

**Change**: Replaced the "skip complex clustering" section with actual composite cluster generation.

**Added Logic**:
1. **Clustering**: Use `_cluster_combinations()` function to cluster combination profiles
2. **Composite DataFrame**: Create DataFrame with `composite_cluster_id` and `combination_key`
3. **Intensity Scores**: Generate intensity scores for each cluster
4. **File Persistence**: Save three key files:
   - `{exchange}_{symbol}_hmm_composite_clusters_{timeframe}.parquet` - Main composite clusters
   - `{exchange}_{symbol}_hmm_composite_intensity_{timeframe}.parquet` - Intensity scores
   - `{exchange}_{symbol}_hmm_composite_meta_{timeframe}.json` - Metadata

**Key Code Added**:
```python
# Cluster the combination profiles to create composite clusters
cluster_labels = _cluster_combinations(profile_df, min_cluster_size=5)

# Create composite cluster DataFrame
composite_df = pd.DataFrame({
    'combination_key': combo_keys,
    'composite_cluster_id': cluster_labels.values,
}, index=out_idx)

# Add intensity scores for each cluster
for cluster_id in range(cluster_labels.max() + 1):
    cluster_mask = cluster_labels == cluster_id
    intensity = cluster_mask.astype(float)
    composite_df[f'intensity_cluster_{cluster_id}'] = intensity

# Save composite clusters
composite_out_path = os.path.join(
    data_dir,
    f"{exchange}_{symbol}_hmm_composite_clusters_{tf}.parquet",
)
_persist_dataframe(composite_df, composite_out_path)
```

## Files Generated by Step 3

After the fix, step 3 will generate the following files for each timeframe:

1. **`{exchange}_{symbol}_hmm_composite_clusters_{timeframe}.parquet`**
   - Contains: `composite_cluster_id`, `combination_key`
   - Purpose: Main regime identification for step 4 and 5

2. **`{exchange}_{symbol}_hmm_composite_intensity_{timeframe}.parquet`**
   - Contains: `combination_key`, `intensity_cluster_0`, `intensity_cluster_1`, etc.
   - Purpose: Intensity scores for each cluster

3. **`{exchange}_{symbol}_hmm_composite_meta_{timeframe}.json`**
   - Contains: Metadata about clusters, distribution, blocks used
   - Purpose: Documentation and analysis

4. **`{exchange}_{symbol}_hmm_block_states_{timeframe}.parquet`**
   - Contains: Individual block states and posteriors
   - Purpose: Detailed HMM state information
