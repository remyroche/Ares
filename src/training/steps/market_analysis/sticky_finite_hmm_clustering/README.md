## Key Features

### Same Infrastructure as HDP-HMM
- ✅ **Identical features**: 50-100 from feature bank
- ✅ **Same data sources**: klines_downloading_processing, data_collection, data_reading
- ✅ **Same quality assessment**: ClusterQualityAssessor with all metrics
- ✅ **Compatible artifacts**: Both `hdp_hmm_*` and `sticky_finite_hmm_*` names

### Enhanced PCA
- ✅ **15 PCA components** (vs 10 for HDP-HMM)
- ✅ Can use up to 20 components

### Comprehensive Reporting (3 CSV Files)

**1. Main Results CSV** (`sticky_finite_hmm_all_results_{timestamp}.csv`)
- Matches HDP-HMM's `hdp_hmm_iterative_all_results.csv` format
- **~70+ columns** including:
  - Core metrics: composite_score, K, base_alpha, kappa, n_clusters
  - Quality: silhouette, DBI, CH, balance
  - **CV metrics**: within/between/ratio + std devs
  - **Temporal**: smoothness (raw + penalized), flip-flop ratio, persistence
  - **Duration distribution**: mean, median, std, min, max
  - **Per-category CV**: order_flow, microstructure, momentum, volatility, volume, trend, temporal
  - **Per-regime metrics**: regime_0_size, regime_0_duration_mean, regime_0_silhouette_mean, regime_0_sharpe_ratio, etc.
  - **Runtime**: processing time, memory, convergence status, final_elbo

**2. ELBO History** (`elbo_history_{timestamp}.csv`)
- Convergence tracking: iteration, elbo, elbo_ma, elbo_improvement

**3. Transition Matrix** (`transition_matrix_{timestamp}.csv`)
- 5×5 stochastic matrix with labeled rows/columns

### Markdown Report
- `cluster_quality_report_{symbol}_StickyFiniteHMM_{timestamp}.md`
- Generated by quality assessor
- Includes all metrics, CV breakdowns, temporal analysis, per-regime statistics

## Usage

```python
from src.training.steps.market_analysis.sticky_finite_hmm_clustering import run_sticky_finite_hmm_step

config = {
    'symbol': 'BTCUSDT',
    'exchange': 'binance',
    'regime_timeframe': '1h',
    'sticky_finite_hmm_params': {
        'K': 5,
        'base_alpha': 0.5,  # Off-diagonal transitions
        'kappa': 10.0,      # Stickiness (10 = ~11 timesteps)
        'num_iters': 800,
        'lr': 1e-2,
        'pca_components': 15  # Can use 15-20
    }
}

results = await run_sticky_finite_hmm_step(config)
```

## Technical Notes

- Uses Gaussian Mixture approximation with learned sticky transition matrix
- ELBO-based convergence (vs state count stability for HDP-HMM)
- KMeans warm start for fast convergence
- All quality metrics from ClusterQualityAssessor
