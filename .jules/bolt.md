## 2024-05-24 - [Numpy Vectorize Performance] Learning: [np.vectorize is simply a convenience wrapper that runs a slow Python for-loop under the hood, resulting in catastrophic performance overhead on large DataFrames when applying math functions like `erf`.] Action: [Always replace `np.vectorize(func)` with native C-level ufuncs like `scipy.special.erf` for mathematical operations on arrays to achieve orders of magnitude speedups (~50x).]
## 2024-05-25 - [Numpy Unique Performance for Remapping] Learning: [Using `np.vectorize(dict.get)` to map values (like compacting cluster labels) performs horribly because it falls back to a Python loop. When remapping arbitrary items to a sequential 0..K-1 index, `np.unique(..., return_inverse=True)[1]` accomplishes exactly this entirely in C.] Action: [Whenever remapping unique items in an array to an integer sequence or enumerating states, use `np.unique(..., return_inverse=True)[1]` instead of dictionaries + vectorize for massive performance gains.]
