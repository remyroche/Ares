# P8U Meta: Relative-GateProxy Target/Query Challenger Bank

## Status

This is a predeclared **offline research** bank. It follows the fail-closed
historical bootstrap of the challenger-relative proxy: the three available
historical banks contained 14 challengers and no candidate that satisfied the
full incumbent-beat contract. No incumbent-relative classifier was fitted or
serialised from that one-class evidence.

The first completed screen receipts (`screen_*_v1`) are retained only as
exploratory diagnostics: their producer omitted the explicit F72
feature-contract path that the downstream descriptor guard requires. The
tested producer repair writes that exact provenance and the `screen_*_v2`
receipts are the only eligible inputs to shortlist or confirmation work.

The existing `GateProxy_P0_Ridge` remains a shortlist tool for new
challengers only. The frozen Under-F120 incumbent is always retained through
the full MC1/portfolio comparison and cannot be displaced by a proxy score.

## Candidate hypotheses

The current Under target declares a robust unexpected favourable outcome only
when the rich-policy residual clears 100 bps and reaches the frozen 0.5 ATR
trailing-activation level. This bank does not change the policy, the Base,
or the score blend. It tests six independently specified alternatives:

| Arm | Change | Hypothesis |
|---|---|---|
| `under_bps75__timestamp` | 75-bps residual hurdle | A less severe hurdle recovers useful conversion opportunities discarded by the 100-bps target. |
| `under_bps125__timestamp` | 125-bps residual hurdle | A stricter hurdle removes marginal upgrades that dilute the Current coordinate. |
| `under_bps100__base_band_block14` | 14-day Base-band query | Under-confidence can be calibration-state dependent rather than purely cross-sectional. |
| `under_bps100__base_band_block21` | 21-day Base-band query | The same state relationship may require a slower, more supported query. |
| `under_bps75__base_band_block14` | lower hurdle + state query | Recall may improve only if the model is allowed to group comparable Base states. |
| `under_bps125__base_band_block21` | stricter hurdle + state query | Precision may improve only under longer supported Base-state groups. |

The first stage uses the frozen F72 target-free feature source and one common
LightGBM Rank-XENDCG model. It therefore isolates target/query semantics.
Only after a target-free score ledger and outcome-separated descriptors are
complete may the frozen GateProxy nominate new challengers for a bounded
Under-F120/F123 feature-contract and HPO stage.

## Selection and promotion rules

1. Persist strict-OOF scores for January–July 2026 before opening held
   outcomes.
2. Produce the standard target-free descriptor receipt.
3. Carry the Under-F120 incumbent automatically; use `GateProxy_P0_Ridge`
   only to nominate three new candidates plus an uncertainty/diversity probe.
4. The primary shortlist receives the bounded three-geometry LambdaRank HPO
   bank in `strict_r3_p8u_meta_relative_gateproxy_bounded_hpo_20260831_v1.json`:
   inherited Under, shallow sparse, and compact tail-gain. This is the only
   model/loss HPO variation in this bank. Each target/query/HPO tuple has a
   distinct immutable trial name; generic HPO names may not be reused across
   target/query roots because the downstream proxy requires unambiguous trial
   lineage.
5. The frozen GateProxy then ranks those target/query/HPO combinations. Only
   its nominated combinations receive the Under-F120 and F123 additive
   feature-contract comparison.
6. Rebuild independent strict-prequential BCF and Current MC1 maps, apply the
   dual `>= +50 bps` gate, and run one chronological constrained portfolio.
7. Promote only when the full incumbent-beat contract passes. Until then, all
   candidates are challengers.

No selection is based on a global IC, a hand-weighted HPO metric, or an
in-sample score-to-net relationship. The primary decision remains actual
downstream, constrained, dual-MC1 economic performance.

## Boundaries

- No live configuration, model, MC1 map, admission threshold, policy, or
  exchange component changes.
- The existing 2026 period is research evidence for this bank, not untouched
  promotion evidence.
- The challenger-relative proxy stays unsupported until the accumulated banks
  include both qualifying winners and non-winners under its frozen contract.
