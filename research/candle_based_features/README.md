# Candle-Based Features Research Module - Consensus-Based Trading Indicators

This research module provides a comprehensive system for generating trading indicators based on candlestick patterns using machine learning models with consensus validation and interpretability analysis.

## 🎯 Key Features

### **Consensus-Based Approach**
- **Multi-Model Validation**: Only uses indicators generated by multiple ML models
- **Agreement Thresholds**: Configurable minimum agreement between models
- **Reliability Scoring**: Model reliability assessment and weighting
- **Quality Control**: Automatic validation of consensus indicators

### **Comprehensive Model Support**
- **LightGBM**: Fast gradient boosting with excellent performance
- **Random Forest**: Robust ensemble method with good interpretability
- **GRU**: Gated Recurrent Unit for sequence modeling
- **TFT**: Temporal Fusion Transformer with attention mechanisms

### **Advanced Interpretability**
- **SHAP Analysis**: Feature importance and model explanations
- **Consensus Features**: Features important across multiple models
- **Model Agreement**: Analysis of agreement between different models
- **Feature Interactions**: Understanding of feature relationships

### **Real-time Generation**
- **Live Consensus**: Generate indicators in real-time
- **Stability Monitoring**: Track consensus stability over time
- **Quality Validation**: Continuous quality control
- **Performance Tracking**: Monitor system performance

## ⚡ Real-time Usage

### Live Trading Integration

```python
class ConsensusTradingSystem:
    def __init__(self):
        self.consensus_system = create_consensus_system()
        self.is_trained = False
    
    def train(self, historical_data):
        self.consensus_system.train_consensus_system(historical_data)
        self.is_trained = True
    
    def generate_signal(self, current_data):
        if not self.is_trained:
            return None
        
        consensus_result = self.consensus_system.generate_consensus_indicators(current_data)
        
        if 'error' in consensus_result:
            return None
        
        indicators = consensus_result['consensus_indicators']
        reliability = consensus_result['reliability_levels']
        
        # Only use high-reliability indicators
        if reliability.iloc[-1] in ['high', 'medium']:
            return indicators.iloc[-1]
        
        return None
```

### Trading System Integration

```python
class ConsensusTradingStrategy:
    def __init__(self, symbol):
        self.symbol = symbol
        self.consensus_system = create_consensus_system()
        self.is_trained = False
    
    def on_data(self, data):
        if not self.is_trained:
            self.consensus_system.train_consensus_system(data, symbol=self.symbol)
            self.is_trained = True
        
        consensus_result = self.consensus_system.generate_consensus_indicators(data)
        
        if 'error' not in consensus_result:
            indicators = consensus_result['consensus_indicators']
            reliability = consensus_result['reliability_levels']
            
            signal = indicators.iloc[-1]
            reliability_level = reliability.iloc[-1]
            
            if reliability_level in ['high', 'medium']:
                if signal > 0.6:
                    self.buy()
                elif signal < 0.4:
                    self.sell()
```
