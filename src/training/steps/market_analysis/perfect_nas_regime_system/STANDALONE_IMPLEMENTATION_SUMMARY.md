## 🚀 **Usage Examples**

### **Standalone Mode (No External Dependencies):**
```python
from perfect_nas_regime_system import PerfectNASConfig, PerfectNASRegimeDetector

# Create configuration
config = PerfectNASConfig.create_short_term_trading_config()

# Initialize standalone detector (no external dependencies)
detector = PerfectNASRegimeDetector(config, use_standalone=True)

# Detect regimes with complete independence
result = detector.detect_regimes(
    market_data=market_data,
    timestamps=timestamps,
    optimize_architecture=True,
    enable_meta_learning=True
)
```

### **Enhanced Mode (With Tool Integration):**
```python
# Initialize enhanced detector (with tool integration)
detector = PerfectNASRegimeDetector(config, use_enhanced=True)

# Detect regimes with full tool integration
result = detector.detect_regimes(
    market_data=market_data,
    timestamps=timestamps,
    optimize_architecture=True,
    enable_meta_learning=True
)
```

### **Original Mode (Backward Compatibility):**
```python
# Initialize original detector
detector = PerfectNASRegimeDetector(config, use_enhanced=False, use_standalone=False)

# Detect regimes with original implementation
result = detector.detect_regimes(
    market_data=market_data,
    timestamps=timestamps,
    optimize_architecture=True,
    enable_meta_learning=True
)
```
