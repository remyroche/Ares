# Causal Gatekeepers Explanation

## What are Causal Gatekeepers?

Causal Gatekeepers are a set of **Meta-Learner models** (specifically LightGBM Classifiers) that serve as the final validation layer in the **De Prado 2026 Causal Protocol Pipeline**. Their primary role is to determine if the causal signals generated by the system are robust enough to predict specific market outcomes.

They are defined and trained in `src/training/steps/labeling/label_based_layer_2_deprado.py` (specifically within the `_train_causal_gatekeepers` method).

## The 7 Gatekeepers

The "7 Causal Gatekeepers" mentioned in the logs correspond to specific binary target outcomes that the system attempts to predict. These targets represent different trading horizons and styles:

1.  **TBM_32**: Triple Barrier Method outcome with a horizon of 32 bars.
2.  **Trend_150**: Trend-following outcome over 150 bars.
3.  **TBM_16**: Triple Barrier Method outcome with a horizon of 16 bars.
4.  **TBM_64**: Triple Barrier Method outcome with a horizon of 64 bars.
5.  **Trend_75**: Trend-following outcome over 75 bars.
6.  **Trend_300**: Trend-following outcome over 300 bars.
7.  **Vol_Spike_Out**: A specific outcome related to volatility reversion (e.g., successful reversion after a spike).

Each Gatekeeper is a distinct model trained to predict one of these specific "Labels" based on the same input data.

## Input: The "Wide Vector" from ORF Chasers

The input features for these Gatekeepers are not raw market data. Instead, they consume a **"Wide Vector"** constructed from the outputs of **8 Orthogonal Random Forest (ORF) Chasers**.

*   **The Specialists (Treatments):** The system first generates signals from 8 primary specialists (e.g., Volume, Volatility, Liquidity, Information, Inventory, Causal Surprise, Microstructure, Pressure).
*   **The Chasers (ORF):** For each specialist, an Orthogonal Random Forest (ORF) model "chases" the signal. It estimates the **Conditional Average Treatment Effect (CATE)**—i.e., the causal "Lift" that the specialist's signal provides in the current market regime.
*   **The Wide Vector:** The metrics from these 8 Chasers (e.g., predicted lift, standard error, heterogeneity scores) are concatenated into a single wide feature vector (`X_meta`).

The Gatekeepers thus learn *which combination of specialist causal estimates* is trustworthy for a given target horizon.

## Relationship to the "Models Race"

The Causal Gatekeepers and the "Models Race" operate at different levels of the architecture:

*   **The Models Race (Bottom-Up Optimization):**
    *   **Focus:** Optimizing the **Signal Generation**.
    *   **Process:** It runs a race between different model types (LGBM, XGBoost, CatBoost) to find the best configuration for *individual* specialists (e.g., finding the best way to calculate a Volatility signal).
    *   **Outcome:** A set of optimized "Geometry Candidates" (specialist signals).

*   **The Causal Gatekeepers (Top-Down Validation):**
    *   **Focus:** Validating the **Causal Efficacy**.
    *   **Process:** It takes the signals from the specialists (the winners of the races) and uses Causal Inference (ORF) to estimate their actual impact (Lift). It then uses Meta-Learners (Gatekeepers) to aggregate these estimates and make a final go/no-go decision for different horizons.
    *   **Outcome:** A set of validated probabilities for different market outcomes (`TBM_32`, `Trend_150`, etc.), determining *if* the trade should be taken.

In summary, the **Models Race** builds the best possible *predictors*, while the **Causal Gatekeepers** act as the *judges* that verify if those predictors are actually working causally in the current environment before authorizing a trade.
