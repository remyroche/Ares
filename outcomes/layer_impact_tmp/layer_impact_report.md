### 2.1 Definitions (as computed by this script)
- **Future_Return**: `close.pct_change(24).shift(-24)` sampled at `events`.
- **Winner / Loser**: Winner if `Future_Return > 0`, Loser otherwise.
- **IC_AbsRet_Pearson / Spearman**: correlation(weight, `abs(Future_Return)`). Baseline is constant so IC becomes NaN.
- **IC_Ret_Pearson**: correlation(weight, `Future_Return`) (directional).
- **Quality component note**: this script uses an ex-ante proxy (`rank_pct(abs(ret_1)/volatility_1d)`) at event time; production should use OOF probabilities / confident-learning scores.
