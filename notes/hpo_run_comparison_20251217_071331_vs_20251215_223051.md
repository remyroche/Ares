---

## What “magnitude-aware” means in this pipeline
### Layer 2 / training target (classification target)
- **`l2_labels_bin`** = binarized triple-barrier outcome (hit TP before SL).
- This is *not* magnitude-aware by itself; it is a **hit/miss** label.

### Layer 1 / sample weighting (magnitude-aware)
- Positive samples can be weighted proportionally to **realized return magnitude** (scaled + clipped), while negative samples receive a smaller constant weight.
- This makes optimization **magnitude-aware** without changing the classification label.

### Layer 3
- Layer 3 model quality is evaluated via utility that includes stability and gating terms.
- Even if the model has good AUC/Sharpe, **utility can be rejected** when trade density is too low.
