# Google Sheets Apps Script webhook exporter

This project exports task rows to Google Sheets by calling a Google Apps Script Web App. This lets a regular Google account append rows without a Google Cloud service-account JSON file.

## Apps Script code

Open the target Google Sheet, go to **Extensions > Apps Script**, and paste this code:

```javascript
const WEBHOOK_SECRET_PROPERTY = "WEBHOOK_SECRET";

function doPost(e) {
  try {
    const props = PropertiesService.getScriptProperties();
    const expectedSecret = props.getProperty(WEBHOOK_SECRET_PROPERTY);

    if (!expectedSecret) {
      return jsonResponse({
        ok: false,
        error: "server_missing_secret"
      }, 500);
    }

    if (!e || !e.postData || !e.postData.contents) {
      return jsonResponse({
        ok: false,
        error: "missing_body"
      }, 400);
    }

    const data = JSON.parse(e.postData.contents);

    if (data.secret !== expectedSecret) {
      return jsonResponse({
        ok: false,
        error: "unauthorized"
      }, 403);
    }

    if (!data.sheet_id) {
      return jsonResponse({
        ok: false,
        error: "missing_sheet_id"
      }, 400);
    }

    const ss = SpreadsheetApp.openById(data.sheet_id);
    const sheet = ss.getSheetByName("Sheet1") || ss.getSheets()[0];

    sheet.appendRow([
      data.job_id || "",
      data.task || "",
      data.status || "",
      new Date()
    ]);

    return jsonResponse({
      ok: true
    }, 200);

  } catch (err) {
    return jsonResponse({
      ok: false,
      error: String(err)
    }, 500);
  }
}

function jsonResponse(payload, statusCode) {
  // Apps Script ContentService does not reliably support custom HTTP status codes
  // for all web app contexts, so statusCode is included in the body for debugging.
  payload.statusCode = statusCode;

  return ContentService
    .createTextOutput(JSON.stringify(payload))
    .setMimeType(ContentService.MimeType.JSON);
}
```

## Manual setup

1. Open the target Google Sheet.
2. Go to **Extensions > Apps Script**.
3. Paste the Apps Script code above.
4. In Apps Script, open **Project Settings**.
5. Under **Script Properties**, add:
   - Key: `WEBHOOK_SECRET`
   - Value: a long random secret generated by you
6. Select **Deploy > New deployment**.
7. Select type: **Web app**.
8. Set **Execute as** to **Me**.
9. Set **Who has access** to **Anyone**. The Python backend is not logged into a Google account; the shared secret authorizes writes.
10. Deploy and copy the Web App URL. The current deployed URL is `https://script.google.com/macros/s/AKfycby4gOibAc7K3iAepbaxqU-2MQXaGsaOVkW_MfcihxxOGW3aKOib5fSvR386u8u519dUqw/exec`.
11. Set local/server environment variables:
    - `SHEETS_WEBHOOK_URL=https://script.google.com/macros/s/AKfycby4gOibAc7K3iAepbaxqU-2MQXaGsaOVkW_MfcihxxOGW3aKOib5fSvR386u8u519dUqw/exec`
    - `SHEETS_WEBHOOK_SECRET=<same secret stored in Apps Script Script Properties>`

## Secrets and sheet IDs

- `SHEETS_WEBHOOK_URL` is copied from Apps Script after deploying the Web App.
- `SHEETS_WEBHOOK_SECRET` is not provided by Google. Generate it yourself and store the same value in:
  1. Apps Script **Project Settings > Script Properties > WEBHOOK_SECRET**
  2. The Python app environment variable `SHEETS_WEBHOOK_SECRET`
- `sheet_id` is not secret. It is the ID from the Google Sheet URL: `https://docs.google.com/spreadsheets/d/<THIS_PART_IS_THE_SHEET_ID>/edit`

Generate a secret with:

```bash
python - <<'PY'
import secrets
print(secrets.token_urlsafe(32))
PY
```

## Security notes

- Never commit `SHEETS_WEBHOOK_SECRET` to Git.
- Never print `SHEETS_WEBHOOK_SECRET` in logs.
- Keep `.env` ignored by Git.
- The Apps Script Web App must validate the secret before writing.
- Keep the Sheet private unless you explicitly want public access.
